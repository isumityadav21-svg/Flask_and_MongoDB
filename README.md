# Flask & MongoDB Assignment

## Project Overview

This project is a Flask web application integrated with MongoDB Atlas.

The application provides:

1. A JSON API route at `/api`
2. A frontend form
3. MongoDB Atlas data insertion
4. Success redirection
5. Error handling on the same page

## Technologies Used

- Python
- Flask
- MongoDB Atlas
- PyMongo
- HTML
- CSS
- Git
- GitHub
